## 📦 Sports Center Frontend – Day 27 (Paging, Sorting, Filtering)

This branch focuses on implementing an interactive and dynamic catalog page for better product browsing.

### ✅ Day 27 Highlights
1. Implemented **pagination**, **sorting**, and **filtering** on the catalog page.
2. Fetched **brands** and **types** dynamically from the backend.
3. Created catalog page layout using Material UI components.
4. Managed state using **React hooks** for filters and selected options.
5. Modified `agent.ts` to support filtered and paginated product requests.
6. Implemented key methods:
   - `loadProducts`
   - `handleSortChange`
   - `handleBrandChange`
   - `handleTypeChange`
